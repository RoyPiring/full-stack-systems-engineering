## What this domain covers

Application and developer-facing engineering across the stack: language runtimes, API contracts, service code, request boundaries, test harnesses, and the local toolchain a build depends on. The work an engineer does by hand rather than the platform underneath it.

**What it isn't.** A framework comparison. A claim of production scale or uptime.
